OpenCode new

engy is in OpenCode's provider list, so there is no base URL to set. Run opencode, then:

/connect      ← pick engy, paste your API key
/models       ← pick an engy model

/connect saves the key in ~/.local/share/opencode/auth.json. To use an environment variable instead, export ENGY_API_KEY=… before you start opencode.

To make an engy model the default, in ~/.config/opencode/opencode.json (or opencode.json in a project):

{
  "$schema": "https://opencode.ai/config.json",
  "model": "engy/glm-5.2"
}

Model ids are engy/ plus an id from the models list: engy/kimi-k3, engy/qwen3.8-27b, engy/deepseek-v4.1-flash. OpenCode reads each model's context window and price from its catalog, so there is no suffix to add as with Claude Code.

Reasoning effort is a variant. Press ctrl+t in the TUI to cycle through a model's variants, or pass one on the command line:

opencode run --model engy/glm-5.2 --variant max "Review this migration"

The variants are the levels each model takes, lowest first: high and max on GLM-5.2; low, high and max on GLM-5.3 and DeepSeek; low, medium and xhigh on Qwen3.8. Kimi-K3 and Qwen3.6 only switch thinking on or off, so they have none. A name that is not in the list is ignored and the model runs at its default. Add your own in the config, next to the built-in ones; the value is sent as reasoning_effort, and engy maps it as shown in What each model hears:

{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "engy": {
      "models": {
        "qwen3.8-27b": {
          "variants": {
            "off": { "reasoningEffort": "none" }
          }
        }
      }
    }
  }
}

off works on every model except GLM-5.3 and GLM-5.3-Flash, which cannot turn thinking off (see Turning thinking off).

engy is in OpenCode's provider list, so there is no base URL to set. Run opencode, then:

/connect      ← pick engy, paste your API key
/models       ← pick an engy model

OpenCode 2 runs models from a background server, so an environment variable has to be given to that server rather than exported in your shell:

opencode service set env ENGY_API_KEY …

To make an engy model the default, in ~/.config/opencode/opencode.jsonc (or opencode.jsonc in a project):

{
  "$schema": "https://opencode.ai/config.json",
  "model": "engy/glm-5.2"
}

Model ids are engy/ plus an id from the models list: engy/kimi-k3, engy/qwen3.8-27b, engy/deepseek-v4.1-flash. OpenCode reads each model's context window and price from its catalog, so there is no suffix to add as with Claude Code.

Reasoning effort is a variant. Add it after the model id with #:

opencode run --model 'engy/glm-5.2#max' "Review this migration"

The variants are the levels each model takes, lowest first: high and max on GLM-5.2; low, high and max on GLM-5.3 and DeepSeek; low, medium and xhigh on Qwen3.8. Kimi-K3 and Qwen3.6 only switch thinking on or off, so they have none. A name that is not in the list is an error. Add your own in the config, next to the built-in ones; the value is sent as reasoning_effort, and engy maps it as shown in What each model hears:

{
  "$schema": "https://opencode.ai/config.json",
  "providers": {
    "engy": {
      "models": {
        "qwen3.8-27b": {
          "variants": [
            { "id": "off", "settings": { "reasoningEffort": "none" } }
          ]
        }
      }
    }
  }
}

Then use --model 'engy/qwen3.8-27b#off'. It works on every model except GLM-5.3 and GLM-5.3-Flash, which cannot turn thinking off (see Turning thinking off).

Tested 2026-10-24 on OpenCode 1.19.4: all nine engy models listed and answered; the variants above are what OpenCode built from the catalog; --variant max and the default model from opencode.json work; the off variant gave 0 reasoning tokens.
Tested 2026-10-24 on OpenCode 2.0.29: all nine engy models listed; engy/glm-5.2#max answered; engy/qwen3.8-27b#high was refused as unavailable. the custom off variant gave 0 reasoning tokens.
