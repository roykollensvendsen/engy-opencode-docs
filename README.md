# engy docs: proposed OpenCode section

An **unofficial** mockup of the layout of [engy.ai/docs](https://engy.ai/docs), made to propose a section on using [OpenCode](https://opencode.ai) with engy. It is not engy's site and is not affiliated with or endorsed by engy. engy's own sections are shown as placeholders; only the proposed OpenCode text is written out.

- Page: https://roykollensvendsen.github.io/engy-opencode-docs/
- The OpenCode section is proposed in a pull request, with `VERIFICATION.md` describing how each statement was checked.

engy's provider entry in the OpenCode catalogue comes from [models.dev](https://models.dev) ([anomalyco/models.dev#5910](https://github.com/anomalyco/models.dev/pull/5910)).
